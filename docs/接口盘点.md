## 使用方法

列出接口用 `python3 adspilot.py --list`。例如 `python3 adspilot.py judge.judge --input tests/fixtures/interfaces/judge.judge.request.json`。每个接口可用同名请求样例或运行 `python3 adspilot.py <id> --selftest`。stdout 为 JSON，退出码 0/2/3/4/1 分别表示成功、需本人、外部失败、配置错误、其他错误。

默认离线。脚本原本必须联系外部服务的动作返回含 dry_run、interface、action 的计划；它只说明待执行的动作。可在本地重放的数据直接调用原脚本。请求和本地配置必须同时允许 apply 才会联网或提交写动作。日循环按指定配置留下本地报告。服务商凭据仅由环境传入；私有账本/转化文件通过 data/ 或 runs/ 下文件引用，不把点击标识放进请求。

仅合规过滤。Cloudflare 的 roundtrip 和开局 verify 原脚本会走测试点击；接口不开放该探测。开局的 campaign/deploy/offers/page/go/teardown/status 使用 step，账本的 mint/stats/lookup/record/import/pull/export 使用 operation；含点击标识的数据仅用本机私有文件导入。

生成注册表和本盘点：`python3 -m core.agent.interfaces --generate`；随后跑 `python3 core/selfcheck/validate.py --interfaces` 与 `python3 adspilot.py --selftest`。

2.1.1 的本地工具始终离线。先执行 `echo '{"days":7,"runs_dir":"runs/fixture-week"}' | python3 adspilot.py loop.simulate`。再把 `{"runs_dir":"runs/fixture-week"}` 分别交给 `selfcheck.acceptance`、`judge.calibrate`。验收不足七天返回退出码 1 和 fail 原因。校准只在所选运行目录保存提议，并返回各阈值的样本数。默认只用同币种或同轮留存的换算记录。显式传 `use_config_fx: true` 才允许当前配置作参考，输出的 `reference_configuration` 与 `per_run_configuration` 分开计数。三个接口均将文件限制在所选本地配置的运行/数据目录；验收和校准也可读取自己的真实跑数目录。
