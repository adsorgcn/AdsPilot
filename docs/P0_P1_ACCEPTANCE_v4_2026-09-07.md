## 你怎么验收

将本次版本化 ZIP 导入支持 Skill 的 AI 平台，或让 AI 读取本仓库
`skills/adspilot/SKILL.md`。这两种方式都不要求你执行开发命令。

第一句话可以直接发给你的 AI：

> 加载 AdsPilot，按包内验收说明检查你的工具与我的任务。
> 先用模拟资料演练，再检查实际连接；默认不创建广告、不花钱、不上传转化。
> 已知的信息不要再问我，只告诉我真正缺少的内容及下一步。

使用包内 [验收说明](../skills/adspilot/references/acceptance.md)。你重点看：

1. 没有连接时，能否给出有用的草案和准确接入动作，而非要求安装服务器。
2. 有多个账户、不同币种或旧授权时，是否只使用你指定的账户和预算。
3. 报表能读、关键词规划不可用时，是否准确区分权限，保留未知指标。
4. 创建超时后是否先核对，不重复建广告、不擅自调整预算。
5. 佣金重复、退款、分页中断、无法归因时，是否仍对得清钱并隔离待确认项。
6. 转化“收到请求”和“逐条确认”的结果是否分开，是否避免重复上传。

开发检查不要求实际 Google/CJ 凭据。真实阶段必须有平台提供的受保护连接、
所需工具和有效授权；缺少时应给出具体能力/本人操作卡，不能假装实测成功。

## 贡献者复现

```sh
node scripts/verify-release.mjs
node scripts/verify-release.mjs --adapters
python scripts/package-agent.py
```

第一条覆盖主产品和协议；第二条另加可选活动 Go 适配器。需要不同开发用 Python/
Go 时使用 `--python`/`--go`；离线协议缓存使用 `--ilang-cache`。无需 `npm install`。
打包单独执行且不会覆盖同名旧包。源码、测试脚本、真实平台验收的证据分开记录。
