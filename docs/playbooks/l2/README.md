## 0. 一句话任务

把 `github.com/adsorgcn/AdsPilot` 里值钱的方法（sub-id 归因、离线转化回灌、Google Ads 建广告硬参数、联盟 offer 选择）写成 **学员自己的 AI 能直接执行的 L2 工程书**，沿用返利网 SOP v2.0 的骨架，六章，附带三个小脚本；AdsPilot 仓库本轮只加文档不删代码。**不做软件，不做 API 底座，不做任何要我们维护和售后的东西。**

## 1. 已经定死的口径（不要再讨论，直接遵守）

1. **真实身份，一个号，一个号七段做完就是跑通**，不以钱到账为条件。多号、放大、矩阵一律不写，学员问就答「不在本群范畴，去会员微信群咨询」。
2. **不做软件，做工程书。** 执行者是学员自己的 AI（ChatGPT 桌面版、Claude 或任何品牌，用户自选），跑在学员自己的日本 VPS 远程机上，手机 remote 全控。工程书里一律写「你的 AI」，只在个别步骤标注不同 AI 的差异。
3. **不依赖 Google Ads API。** 原因是 2026 到 2027 年 Google 连续四项变动：developer token 迁 Google Cloud 项目（2027 上半年废弃旧模式）、离线转化导入从 `UploadClickConversions` 迁到 Data Manager API、API 版本每三到四个月强制升级一次、新 OAuth refresh token 要求 passkey。学员在自己浏览器里操作 Google Ads 后台，离线转化用后台 CSV 上传或 Google Sheets 模板导入，全程不碰 API。
4. **风控不是拦路石。** 学员用真实身份、真实账号，AI 代操作触发验证就按提示解释和补验证。工程书里保留人机分工：证件 KYC、绑卡付款、密码验证码 2FA、首次登录授权、后台里建系列改出价传转化这几下由学员本人点；选 offer、查政策、算数、写文案、跑脚本、出报表由 AI 做。AI 拒绝的那一步本来就该本人做，不硬逼不教绕。
5. **红线（不许出现在工程书里）**：冒充身份、生成外国人资料、临时邮箱注册、同一受益人多账号伪装、用工具绕平台资格或封禁、自动注册养号脚本、做完删环境规避追溯、cloaking、假流量假点击、转账用途填与实际不符的理由。指纹浏览器和住宅 IP 允许写，定位是环境隔离和看目标市场真实结果，本人真实信息注册，一个专用配置，静态会话，不用机房 IP，不乱换出口。
6. **禁词**：翻墙、科学上网、梯子、VPN、代理工具、加速器 这一族一律不出现，要表达远程机能访问海外站点就写「远程机在海外，它自己就能访问」。
7. **我们的 Google Ads API 只归我们用。** 它的 developer token 与配额只有两个用途：我们自己开发测试，机器人在教练回合里当尺子（咒语出词量、审选词）。**不对学员提供服务，工程书任何章节不得引用我们的接口、端点或凭据；不做批量查词之类的自助能力。** 学员查词用自己 Google Ads 账号里的 Keyword Planner，建广告和离线转化回灌用自己的后台。（老板 09-25 定）
8. **L2 硬依赖 L1**：四样前置是 在跑的返利网账号、会用指纹浏览器、投过 Google Ads、收款链路已通。缺哪样按 L1 补，不跳步。

## 3. 交付物

### 3.1 六章工程书（Markdown，UTF-8，放 `Projects\工程书-AdsPilot转L2工程书\输出\`）

文件名统一：`SOP-广告联盟双轨-迭代版-v2.0-第N章-<章名>-2026-MM-DD.md`。每章独立成文，能单独发给学员的 AI 执行。

| 章 | 名 | 必须回答的问题 | 附带 |
|---|---|---|---|
| 1 | 选联盟与 offer 尽调 | 用本人真实身份能过哪家联盟审核（Awin 要求所有发布者填税务信息，Impact/CJ 对非美国人要 W-8BEN）；怎么反查商家背后的联盟；一个 offer 的 go/no-go 判据：流量带、cookie 时长、佣金与锁定期、**PPC 与品牌词竞价政策**、避雷品类、允许的流量类型 | 尽调卡模板（表格） |
| 2 | 落地页合规 | 按 Google 目的地要求，直链和桥页会被拒登；一个能过审的页面长什么样：实质内容、原创价值、联系方式、隐私与条款与联盟披露、CTA 走自己域名下的中转再跳联盟、Final URL 不自动跳转、移动端可用 | 自检清单；最小页面骨架（HTML） |
| 3 | sub-id 追踪与映射 | 32 位以内纯字母数字 token 生成；token 进联盟 sub-id；映射表 `token → gclid, campaign, adgroup, keyword, page, timestamp, network, offer`；三种注入形态里默认用「落地页 + 第一方标签」，直链形态只作说明并标注政策风险，ValueTrack 维度级作为零基建的兜底 | **脚本 A**：`subid_map.py`（Python 3 标准库 + SQLite，生成 token、写映射、导出）；**脚本 B**：`redirect.py` 或 Cloudflare Worker 版中转（读 gclid 写 token 后 302） |
| 4 | 建广告的硬参数与自证输出 | 匹配方式只许词组或精确；Search Partners 与 Display 关；目标地理按目标市场 living in；Manual CPC 起投与上限；日预算与爬坡节奏；否定词；新账号别一上来大预算、别频繁改动触发复审 | **自证格式**：学员的 AI 把系列设置导出成固定字段的 JSON 贴回群里（campaign、adgroup、match_types、networks、geo、cpc、daily_budget、final_url_domain、negatives_count） |
| 5 | 对账与离线转化回灌 | 联盟后台导出佣金明细（含 sub-id）；token join 映射表还原 gclid；按 Google Ads 后台离线转化导入模板生成 CSV（gclid、转化名、时间、金额、币种）；在后台「上传」入口导入；拒付和纠正记录如何反标 | **脚本 C**：`reconcile.py`（读联盟 CSV 与映射表，出 Google Ads 导入 CSV） |
| 6 | 收款与税表材料 | 本人实名收款账户；W-8BEN 填法；Awin 税务信息表；PayPal 中国跨境收款的「真实交易背景」要准备什么材料（联盟协议、后台截图、自开票 PDF）；Wise 与 Payoneer 的实名流程；转账用途如实填 | 材料清单 |

每章末尾固定两段：**什么算这一段做完**（对应七段骨架的哪一段、交什么截图或自证 JSON，格式照 `S32_LINES-11` 的写法）和**什么不许做**（从第 1 节红线里抄相关条目，不要自己发挥）。

### 3.2 三个脚本

- 放 `Projects\工程书-AdsPilot转L2工程书\输出\scripts\`，同时提交到仓库 `docs/playbooks/l2/scripts/`。
- Python 3.10+，**只用标准库**（sqlite3、csv、secrets、http.server），零依赖，学员的 AI 在任何 VPS 上都能直接跑。
- 每个脚本自带 `--selftest`，跑完打印 `SELFTEST OK`；每个脚本顶部注释写清 输入、输出、不做什么。
- 脚本不联网访问联盟或 Google 的 API，只处理本地文件。

## 4. 验收标准（老板亲自或让自己的 AI 在一台 VPS 上过一遍）

1. 六章任何一章单独交给一个没有上下文的 AI，它能按步骤执行，不需要追问「什么意思」。
2. 三个脚本 `--selftest` 全部 `SELFTEST OK`；`subid_map.py` 生成的 token 满足 32 位以内纯字母数字；`reconcile.py` 用样例联盟 CSV 能产出可被 Google Ads 后台接受的导入 CSV（字段名与时间格式按后台模板）。
3. 第四章的自证 JSON 能由学员的 AI 从 Google Ads 后台界面读出来填全，不需要 API。
4. 全文跑一遍红线与禁词检查：第 1 节第 5、6 条列出的词与做法一个都不出现（`grep` 即可）。
5. 每章的「什么算这一段做完」能一一对上七段骨架（前置与环境 / 选 / 搭 / 首跑 / 数据达标 / 收款就绪 / 跑通）。
6. 通篇没有破折号。

## 5. 老板还没拍板的两件（开工前问一次，问完不再问）

1. **落地页在 L2 是必选还是可选。** 建议必选，理由是 Google 今年对直链和桥页的判罚会让段 4 的账号存活率成为最大变量。如果老板定可选，第二章保留，第三章默认形态改为「直链 + 跳转注入」并把政策风险写在最前面。
2. **sub-id 语义。** 建议 per-click：一次点击一个 token，不轮换，映射表只增不改。老板点头就按这个写第三章。

## 6. 工作方式

- 先读：本文、`docs/HANDOFF.md` 第 3、4、11 节、`docs/affiliate-design.md`、返利网 v2.0 全文、S32_LINES 摘录。读完再动笔。
- 写作顺序：第 3 章（最值钱、最难靠学员自己摸出来）→ 第 4 章 → 第 2 章 → 第 1 章 → 第 5 章 → 第 6 章。每写完一章就落盘到 `输出\`，不要攒到最后。
- 事实核验：涉及各联盟 sub-id 参数长度、Google 后台导入模板字段、税表要求，写之前查一次官方页面，把出处链接放在该章「待核验与拿不准」里。查不到就写「待核」，不编。
- 交接给运维会话：每完成一章，在 `Projects\工程书-AdsPilot转L2工程书\交接.md` 追加一行「日期 章号 文件名 状态（草稿/老板已定稿）」。老板定稿后，运维会话负责同步进乐享镜像、改 SOUL 的 `S32_LINES-06` 取值、刷新会话 hash。新会话不做这三步。
- 不要做的事：不碰香港机、不改 SOUL、不写乐享、不删仓库代码、不装依赖、不给多个版本让老板选。
