# 使用方法：schema 与一致性自检

::STATE{@PART, name:selfcheck, kind:core, external_apis:none, entry:core/selfcheck/validate.py}

主干只认 `schemas/` 里的形状。插件产出、本轮报告、判断请求与响应、配置，都用这一个脚本校验。CI 跑的也是它。

```bash
python3 core/selfcheck/validate.py --all            # manifests + config + tests/fixtures 全部样例
python3 core/selfcheck/validate.py --manifests
python3 core/selfcheck/validate.py --config
python3 core/selfcheck/validate.py --report runs/<id>/report.json
python3 core/selfcheck/validate.py --spec runs/spec.json
```

::RULE{改schema⇒同时改用它的脚本与样例 走末位版本}
::RULE{schema里不认识的关键字⇒校验器直接报错 不会悄悄跳过}
