# 使用方法：落地页

::STATE{@PART, name:lp, kind:core, external_apis:none, template:core/lp/templates/landing.html, check:core/lp/lp_check.py}
::OBJECTIVE{id:lp|owner:user|trust:untrusted|version:1|status:active}
  target: 一个能过 Google 目的地要求、对搜索这个词的人有用、CTA 走本站中转的页面
  ACCEPT: lp_check 全过 AND 内容与广告承诺一致 AND 移动端能读
  NON_GOALS: 直投联盟链接、桥页、按访客改内容

## 一个能过审的页面长什么样

实质内容（原创、对搜这个词的人有用、至少 300 词）；隐私政策与条款链接；联系方式；联盟披露；CTA 走本站 `/go?o=<offer_ref>`（`rel="nofollow sponsored"`）；Final URL 不自动跳转；移动端可用；所有访客看到同一内容。

## 步骤

[STEP:1|填模板|by:agent]
复制 `core/lp/templates/landing.html`，把 `{{…}}` 占位符全换成真内容。写的是给人看的评测、对比或指南，不是广告文案的重复。模板里的第一方标签只读 URL 里的 gclid 与 ValueTrack 维度、存第一方 cookie、挂到 `/go` 链接上，不改内容不跳转。

[STEP:2|自检|by:agent]

```bash
python3 core/lp/lp_check.py site/widget-x-review.html
```

有 `FAIL` 就改页面，`lp.publish` 节点在 `lp_check_passed` 为 true 之前只给 `fix`。

[STEP:3|部署|by:agent]
页面放到自有域名（静态托管即可）；`/go` 中转按 `plugins/deploy/cloudflare-worker/使用方法.md` 部署到同一域名。Google Ads 的 Final URL 填这个页面，跟踪模板填 `{lpurl}?c={campaignid}&a={adgroupid}&k={targetid}&n={network}`。

[STEP:4|实测|by:agent]
从目标市场（用户自己的正常网络或住宅 IP）打开一次带 `?gclid=test123` 的页面，点 CTA，确认 302 到带 `sid=` 的联盟链接，再 `subid.py pull` 看映射进了账本。

::EVIDENCE{id:e1|deliverable:page|kind:test_output|ref:"lp_check verdict PASS"|verified_by:@TOOL|result:pass}
::EVIDENCE{id:e2|deliverable:roundtrip|kind:ledger|ref:"pull 后 mappings 增加一行 page=该页"|verified_by:@TOOL|result:pass}

::RULE{广告被以目的地要求拒登⇒完整读原因 改页面 如实申诉一次 不换域名不换账号}
::BOUNDARY{never:桥页_自动跳转_按UA或IP改内容|scope:permanent}
