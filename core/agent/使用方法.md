# 使用方法：Agent 适配与能力自检

::STATE{@PART, name:agent, kind:core, external_apis:none}
::OBJECTIVE{id:agent|owner:user|trust:untrusted|version:1|status:active}
  target: 任何有生产、部署、运营能力的 Agent 读完本目录就能以同一种方式执行仓库里的其他使用方法
  ACCEPT: selfcheck 退出码 0 AND iLang runtime 校验通过 AND config/adspilot.json 存在且过校验
  NON_GOALS: 给某一家 Agent 写特殊分支；仓库里只有一份逻辑

## 谁能当执行者

必备条件只有一条：**有生产、部署、运营能力的 Agent。** 具体是六项，selfcheck 逐项查：能执行命令、能读写文件、能出网、能跑长任务、能部署（git 与 curl，部署插件再要 wrangler 一类）、能被调度器定时拉起。缺一项就判不适用，不硬跑，不教绕。

已知入口：Claude Code 读 `CLAUDE.md`，Codex、OpenClaw、Hermes 与其他读 `AGENTS.md`，Cursor 读 `.cursor/rules/adspilot.mdc`。三份内容相同，只有抬头不同。新 Agent 出现就再加一份抬头不同的入口，正文不改。

## 接口总表

机器读取 [接口注册表](../../schemas/interfaces.json)。每一项列出脚本、请求与响应 schema、退出码、外部 API 和证据状态。[接口盘点](../../docs/接口盘点.md) 对照原脚本参数与样例。

```bash
python3 adspilot.py --list
python3 adspilot.py judge.judge --input tests/fixtures/interfaces/judge.judge.request.json
python3 adspilot.py --selftest
```

同一份请求也可通过 stdin 传入。stdout 只提供 JSON。单个业务接口的退出码沿用插件约定：0 完成，2 需要本人，3 暂时失败，4 凭据或权限问题，1 输入或内部错误。统一入口默认 dry-run，执行外部写入同时要求请求显式 apply 与本机配置中的 `"apply": true`。

## 调工具的 Agent 怎么接

在宿主启动一个本地标准输入输出进程。将下方脚本路径换成 AdsPilot 的绝对路径。Windows 可将 `python3` 换成 Python 可执行文件的完整路径。在服务器启动参数里加 `--config /绝对路径/AdsPilot/config/adspilot.json` 可固定配置；工具请求里不能另选配置。工具名与注册表 ID 相同。宿主界面可能显示自己的前缀或转义后的名字。

DSH 使用一个 Cordis 插件配置项。合入现有插件列表，并启用 DSH 的 MCP 客户端：

```yaml
- id: mcp-adspilot
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: adspilot
    transport: stdio
    command: python3
    args: ['/绝对路径/AdsPilot/core/agent/mcp_server.py']
```

Claude Code 在 AdsPilot 所在机器执行：

```bash
claude mcp add --transport stdio adspilot -- python3 /绝对路径/AdsPilot/core/agent/mcp_server.py
```

连接后先列出工具，再用上面同一份样例调用 `judge.judge`。成功信号是返回 `judgment.response`。本地检查可直接运行 `python3 core/agent/mcp_server.py --selftest`。该服务使用逐行 JSON-RPC，支持 initialize、initialized 通知、tools/list 与 tools/call。远程 API 的报错正文和子进程日志不作为工具结果返回。

## 步骤

[STEP:1|读架构|by:agent]
`[READ:@ARCHITECTURE|src=ARCHITECTURE.md]`。读完你要能说出：判据是什么，哪些是主干，哪些是插件，人只在哪三处出现。

[STEP:2|校验 iLang runtime|by:agent]

```bash
python3 core/agent/ilang_runtime.py verify
```

通过后 `[READ:@ILANG|src=reference/ilang/ilang-latest.md]`。这是钉住版本的正典 runtime，不从网上读。需要更新时 `python3 core/agent/ilang_runtime.py update --apply`，校验 sha256 通过才落盘。

[STEP:3|能力自检|by:agent]

```bash
python3 core/agent/selfcheck.py
```

有一项 `FAIL` 就停，把整段输出贴给用户。`WARN` 可以继续，但要在首轮报告里带上。

Windows 上有四处要知道：`python3` 多半是微软商店的占位别名，用 `python` 跑同一条命令（`tests/run.sh` 会自己找）；控制台是 GBK 时给 Python 加环境变量 `PYTHONUTF8=1`，循环、开局与判断拉起子脚本时会自动带上它；`zoneinfo` 没有系统时区库，`pip install tzdata`，不装则自检给 `WARN`、转化文件按 UTC 带偏移写，时刻不变；钉版本 runtime 在 `.gitattributes` 钉成 LF，老检出被 `core.autocrlf` 改成 CRLF 的也按 LF 核过。

[STEP:4|配置|by:human_then_agent]
用户复制 `config/adspilot.example.json` 为 `config/adspilot.json`，填自己的值。凭据一律放环境变量，配置里只写变量名。`apply` 保持 `false` 直到用户看过一轮 dry-run。

```bash
cp config/adspilot.example.json config/adspilot.json
python3 core/selfcheck/validate.py --config
```

[STEP:5|首轮 dry-run|by:agent]

```bash
python3 core/loop/daily.py --dry-run
```

退出码 0 才算适配完成。之后按 `core/loop/使用方法.md` 装调度。

