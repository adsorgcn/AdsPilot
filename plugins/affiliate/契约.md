# 联盟与广告主插件契约

::STATE{@PLUGIN_KIND, kind:affiliate, first:cj, later:"impact awin rakuten shareasale direct-postback"}

一个联盟插件把 offer 数据、带 sub-id 的链接、佣金明细、拒付四样翻译成主干认的形状。sub-id 里永远只装主干发的 token（32 位内纯字母数字），其余全在主干的映射表里。

## 动作

### offers：offer 发现与尽调数据

输入：筛选条件（品类、国家、最低 EPC 等），或明确的 advertiser id 列表。
输出：offer 列表 JSON，每项至少 `{offer_ref, advertiser, advertiser_id, network, epc, commission, cookie_days, lock_days, ppc_allowed, brand_bidding_allowed, allowed_traffic, category, status}`。取不到的字段填 null，不猜。

::RULE{offers只出数据不做选择⇒选哪个是主干offer.select节点的判断}
::RULE{ppc_allowed与brand_bidding_allowed来自联盟政策字段或商家条款⇒取不到填null 主干按null当不允许}

### link：带 sub-id 的链接

输入：offer_ref、token、可选目标深链。
输出：`{url, sub_id_param, token}`。

::RULE{sub_id参数名由本网络决定|CJ:sid|Impact:subId1|Awin:clickref|Rakuten:u1|ShareASale:afftrack}
::RULE{token必须匹配^[A-Za-z0-9]{8,32}$⇒否则拒绝生成}
::RULE{已有同名参数⇒替换不追加 保留其他参数}

### commissions：佣金明细

输入：时间窗口、publisher id。
输出：`schemas/commissions.schema.json` 形状，`sub_id` 字段装回读到的 token。

::RULE{回读字段按各网络当前schema|CJ:shopperId(sid已废弃)}
::RULE{分页与限流由插件处理 主干只看最终rows}
::RULE{取不到API⇒使用方法给出后台导出CSV加commissions_import的退路 形状不变}

### chargebacks：拒付解析

输入：同 commissions 的窗口，或已拉回的 commissions JSON。
输出：同一形状，只含 `is_chargeback:true` 的行，`amount` 为负，`original_event_id` 指向原事件。

::RULE{拒付行必须能关联到原事件⇒关联不上的单独列出 主干记unknown不做负转化}

## 资格与身份

::RULE{联盟审核要本人资料税表⇒照实填 W-8BEN_或所在地税务信息 不冒充 不生成他人资料}
::RULE{联盟拒绝本人所在国或证件⇒这条线判停 记原因 不注册新号 不换身份}

## manifest 必填

```json
{ "kind": "affiliate", "actions": { "offers": "offers.py", "link": "link.py", "commissions": "commissions.py", "chargebacks": "chargebacks.py" } }
```

::BOUNDARY{never:多账号_他人身份_临时邮箱注册_绕资格审核|scope:permanent}
