# 使用方法 · ipapi.is

只做流量过滤与目标市场核对。插件状态为 alpha，样例使用 RFC 保留文档地址。is_proxy 表示提供者识别到的开放代理，false 不能证明地址属于真人。

```ilang
::BOUNDARY{never:用IP情报做cloaking或按访客身份改内容|scope:permanent}
```

从 [官方账户页](https://ipapi.is/app/) 申请自己账号的 key，在本机环境变量 `IPAPI_IS_KEY` 中提供。注册免费层每日 1,000 次，每个地址计一次。匿名响应没有本插件需要的代理与机房标记。[接口使用方法](https://ipapi.is/developers.html) · [免费层](https://ipapi.is/free-tier.html)

```bash
python3 plugins/ipintel/ipapi-is/lookup.py --selftest
echo '{"ips":["192.0.2.23","2001:db8::23"]}' | python3 plugins/ipintel/ipapi-is/lookup.py
python3 plugins/ipintel/ipapi-is/lookup.py --input /path/to/your-ips.json --apply
```

普通调用只返回与内置样例匹配的行，其他地址返回空 rows。实际查询最多 100 个公网单播地址，通过 HTTPS 的 POST 请求提交给提供者。输出 rows 中每一项只有 ip、country（两位国家代码）、is_datacenter、is_proxy。仅在获得授权的输入上使用；结果在 stdout，插件不写本地日志。缺 key 或输入错误退出 4，服务失败退出 3。
