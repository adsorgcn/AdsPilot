# 关键词数据源插件契约

::STATE{@PLUGIN_KIND, kind:keywords, first:google-ads, fallback:"用户自己 Google Ads 账号里的 Keyword Planner 导出 CSV"}

## 动作

`suggest`：输入种子词（可加网址）与国家，输出候选词列表 `{text, volume, cpc_low, cpc_high, competition, brand}`，外层带 `currency`（广告账户币种）。
`volume`：输入词列表，输出同形状带数据。

`cpc_low` `cpc_high` 是首页出价的低位与高位。选品第一条（词的出价 < 每次点击赚的钱）用的就是它们，用哪一个由 SOUL 的 `offer.bid_metric` 定。

主干在没有关键词插件时，只认 Agent 从用户自己 Keyword Planner 导出的 CSV（`core/lp/` 与 `plugins/traffic/google-ads/spec.py` 都能读）。

::BOUNDARY{never:用iLang_Inc的Google_Ads_API给用户查词|scope:permanent}
