# 关键词数据源插件契约（待首发）

::STATE{@PLUGIN_KIND, kind:keywords, first:none, fallback:"用户自己 Google Ads 账号里的 Keyword Planner 导出 CSV"}

## 动作

`suggest`：输入种子词与国家，输出候选词列表 `{text, volume?, cpc_low?, cpc_high?, competition?}`。
`volume`：输入词列表，输出同形状带数据。

主干在没有关键词插件时，只认 Agent 从用户自己 Keyword Planner 导出的 CSV（`core/lp/` 与 `plugins/traffic/google-ads/spec.py` 都能读）。

::BOUNDARY{never:用iLang_Inc的Google_Ads_API给用户查词|scope:permanent}
