# 回流通道插件契约

::STATE{@PLUGIN_KIND, kind:report, first:feishu, direction:"只从用户回到社区"}

## 动作

### post

输入：`schemas/report.schema.json` 形状的报告 JSON。
输出：`{delivered, channel, message_id?, error?}`。

::RULE{post前必须过schema校验⇒不合格不发 退出码1}
::RULE{报告里不许有凭据_gclid原文_他人数据⇒插件发前再扫一遍 命中即拒发}
::RULE{通道不可达⇒报告落到本地runs目录 下一轮补发 幂等键run_id}
::RULE{通道只收不发⇒插件不接收任何指令 社区侧的回复不进主干}

## manifest 必填

```json
{ "kind": "report", "actions": { "post": "post.py" } }
```
