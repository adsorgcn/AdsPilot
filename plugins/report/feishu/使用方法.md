# 使用方法：飞书回流

::STATE{@PLUGIN, id:report/feishu, direction:"只从用户回到社区", receives:nothing}

[STEP:1|配置|by:human]
在社区领取收集接口地址与密钥，放 `ADSPILOT_REPORT_URL`、`ADSPILOT_REPORT_SECRET`；想在自己的飞书群里看摘要就再放一个自定义机器人的 `ADSPILOT_REPORT_WEBHOOK`。`config/adspilot.json` 里 `report.enabled` 改 true。

[STEP:2|试发|by:agent]

```bash
python3 plugins/report/feishu/post.py --report runs/<id>/report.json           # 只打印摘要
python3 plugins/report/feishu/post.py --report runs/<id>/report.json --apply   # 真发
```

主干每轮末尾自动跑这一步（`config.apply` 或 `--apply` 时真发）。发前过 schema，扫掉凭据与 gclid。

::RULE{通道不可达⇒报告留在runs/<id>/report.json 下一轮补发 幂等键run_id}
::RULE{社区侧的任何回复⇒不进主干 这个通道只收不发}
::BOUNDARY{never:报告里带凭据_gclid原文_他人数据|scope:permanent}
