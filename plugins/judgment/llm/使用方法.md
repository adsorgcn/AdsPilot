# 使用方法：便宜模型做感知层

::STATE{@PLUGIN, id:judgment/llm, layer:perception_only, decision:"主干 f_v5"}

[STEP:1|配置|by:human]
任选一个 OpenAI 兼容的提供商（公益期推荐便宜模型），环境变量放 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。`config/adspilot.json` 里 `judgment.provider` 改为 `llm`。

[STEP:2|试一次|by:agent]

```bash
python3 core/judge/judge.py --node campaign.adjust --state tests/fixtures/state.adjust.json --choices tests/fixtures/choices.adjust.json --provider llm
```

看 stderr 里的 `::JUDGE{v5.0}` 块；`provider` 字段为 `llm` 且 `fallback` 为 false 才算通。模型输出不合格式主干会退回本地规则，不会停。

::RULE{模型报的M与主干f_v5不一致⇒以主干为准 差异进日志}
::RULE{cer或evd低于门槛⇒M5 这是模型诚实说不知道 不要调提示词硬拉高}
::BOUNDARY{never:把凭据_gclid原文_他人数据放进提示词|scope:permanent}
