# 使用方法：托管 SOUL API（公益期）

::STATE{@PLUGIN, id:judgment/soul-api, host:"iLang Inc.", price:0, contract:soul/soul-api.md}

[STEP:1|领密钥|by:human]
公益期在社区领取端点与密钥，放 `SOUL_API_ENDPOINT`、`SOUL_API_KEY`；`judgment.provider` 改为 `soul-api`。可选在 `config.judgment.soul_api` 指定 `dialect: "auto" | "v1" | "ilang-judge"` 与 `rubric: "v5"`。

[STEP:2|发前脱敏与方言适配|by:agent]
发请求前会删除凭据、`gclid`/`gbraid`/`wbraid` 原文与 `ips` 列表（保留布尔 `gclid_all_valid` 与枚举 `gclid_kind`）。`auto` 模式优先发正典 `v1` 请求，遇到 `ilang-judge` 服务返回 422 `need_caller_and_state` 时自动转为 `{caller, state, action, rubric}` 方言重发。

::RULE{超时8秒或非200⇒按provider_chain继续或退回本地规则 记fallback:true}
::BOUNDARY{never:把凭据_gclid原文_他人数据发出去|scope:permanent}
