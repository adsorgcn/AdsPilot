# 使用方法：新增自定义判断插件（感知层）

::STATE{@PLUGIN, id:judgment/<name>, contract:plugins/judgment/契约.md, layer:perception_only}

[STEP:1|复制模板|by:agent]
将 `plugins/judgment/_template/` 复制为 `plugins/judgment/<name>/`，把 `manifest.json` 里的 `id` 改为 `judgment/<name>`，填写 `credentials` 与 `external_apis`。

[STEP:2|实现与注册|by:agent]
1. 完善 `provider.py`，保证支持 `--config`、`--soul` 与 `--selftest`（无凭据离线返回 0）。
2. 检查 manifest 与统一接口注册：

```bash
python3 core/selfcheck/validate.py --manifests
python3 -m core.agent.interfaces --generate
python3 core/selfcheck/validate.py --interfaces
```

[STEP:3|基准评测（上线必过）|by:agent]
在 `config/adspilot.json` 的 `judgment.provider` 或 `judgment.provider_chain` 里填入 `<name>`，跑 L2 基准门槛评测：

```bash
python3 core/judge/eval_provider.py --provider <name> --apply
```

::BOUNDARY{never:在判断插件里自己篡改或跳过f_v5|scope:permanent}
