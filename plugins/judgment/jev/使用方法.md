# 使用方法：Jev 做感知与选项分布

::STATE{@PLUGIN, id:judgment/jev, modes:"systemone | decide", gives:"systemone 给 11 维期望向量与 choice；decide 给 choice 与 distribution", latency:"70 到 500 毫秒"}

[STEP:1|接入|by:human]
放入 `JEV_ENDPOINT`（如 `https://api.typesafe.ai/v1/systemone`）与 `JEV_API_KEY`；`judgment.provider` 改为 `jev`。可选在 `config.judgment.jev` 里指定 `mode: "auto" | "systemone" | "decide"` 与 `model`。

[STEP:2|形状与退路|by:agent]
`provider.py` 按端点后缀或 `config.judgment.jev.mode` 自动选 `/v1/systemone`（11 维 `{0, 0.5, 1}` 题 + `choice` 分布）或早期 `/decide` 端点；选项不超过 255 个，发前脱敏。

若端点走 `/decide`，向量由主干本地规则按 Jev 选的选项打分；若走 `/v1/systemone`，由概率加权期望得出 `v`。模式仍永远由主干按 `f_v5` 算。

::RULE{Jev给的选项不在choices里⇒退出码3 主干按provider_chain或退回本地规则}
