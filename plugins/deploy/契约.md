# 部署目标插件契约

::STATE{@PLUGIN_KIND, kind:deploy, first:cloudflare-worker, what:"落地页与自有域名中转（/go 铸 token 存映射 302 出站）"}

## 动作

### deploy

输入：主干 `core/lp/` 产出的静态页与中转代码、用户自有域名。
输出：`{url, health_url, export_url, applied}`。

### status

输入：无。
输出：`{healthy, version, mappings_pending}`。

::RULE{中转必须在用户自有域名下⇒不用任何共享域名}
::RULE{映射导出接口必须带用户自己的密钥⇒主干ledger/subid.py import拉回本地}
::RULE{deploy默认dry_run⇒只有--apply才真部署}

## manifest 必填

```json
{ "kind": "deploy", "actions": { "deploy": "deploy.sh", "status": "status.sh" } }
```
