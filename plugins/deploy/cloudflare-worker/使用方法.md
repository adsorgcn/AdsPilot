# 使用方法：自有域名中转（Cloudflare Worker）

::STATE{@PLUGIN, id:deploy/cloudflare-worker, routes:"/go /export /health", domain:"用户自有", same_for_everyone:true}

落地页的 CTA 指向本站 `/go?o=<offer_ref>`，第一方标签把 gclid 与 ValueTrack 维度挂上去；Worker 铸 token、存映射、302 到带 `sid=<token>` 的联盟链接。Final URL 仍是落地页，不是这个中转；中转对所有访客一样，不看谁来。

[STEP:1|准备|by:human]
Cloudflare 账号里有自己的域名；`npx wrangler login` 在浏览器里授权本人账号。

[STEP:2|配置|by:agent]

```bash
cd plugins/deploy/cloudflare-worker
cp wrangler.toml.example wrangler.toml            # 填域名、KV id、OFFERS
npx wrangler kv namespace create MAPPINGS         # 把输出的 id 填进 wrangler.toml
npx wrangler secret put EXPORT_KEY                # 随机长串；同一个值放本机环境变量 ADSPILOT_EXPORT_KEY
```

`OFFERS` 里每个 offer_ref 对应一条联盟点击链接与 sub-id 参数名（CJ 是 `sid`）。加 offer 只改这个 JSON 再部署。

[STEP:3|部署|by:agent]

```bash
./deploy.sh            # dry-run
./deploy.sh --apply    # 真部署
./status.sh https://go.example.com
```

[STEP:4|接回主干|by:agent]
`config/adspilot.json` 的 `deploy.export_url` 填 `https://go.example.com/export`，`deploy.export_key_env` 保持 `ADSPILOT_EXPORT_KEY`。主干每轮开头 `subid.py pull` 把新映射拉进本地账本。

::RULE{OFFERS里的url必须是联盟给本人账号的点击链接⇒不是别人的}
::RULE{/go对任何访客返回同一去向⇒不按UA_IP_地区改去向 那是cloaking}
