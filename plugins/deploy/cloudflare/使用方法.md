# 使用方法：Cloudflare 落地位（交钥匙）

::STATE{@PLUGIN, id:deploy/cloudflare, routes:"/<slug> /go /export /health", domain:"用户自有", same_for_everyone:true, human_steps:1}
::OBJECTIVE{id:cf|owner:user|trust:untrusted|version:1|status:active}
  target: 一把钥匙进，用户自有域名上的落地页、/go 中转、/export 拉回全部建好，之后页面与 offer 只是存储写入
  ACCEPT: setup 后 /health 通 AND status --roundtrip 三步全通（页面 200、/go 302 带 sid、/export 里有这个 token）
  NON_GOALS: 买域名（那是付款，本人做）、任何不是本插件建的 Worker 与 DNS

## 交钥匙（本人做，唯一一步）

[STEP:0|钥匙|by:human]
Cloudflare 个人资料页 → API Tokens → Global API Key → View，抄下来放环境变量 `CF_GLOBAL_API_KEY`，登录邮箱放 `CF_EMAIL`。已经有账号级全写 API Token 的放 `CF_API_TOKEN` 也行。域名要在这个账号里（免费档就够）；账号里一个域名都没有的，先去买一个（Cloudflare 里买或转进来），买完就没本人的事了。

## 三个动作（Agent 做）

[STEP:1|setup 建落地位|by:agent]

```bash
python3 plugins/deploy/cloudflare/setup.py --host reviews.example.com            # 先看 plan
python3 plugins/deploy/cloudflare/setup.py --host reviews.example.com --apply    # 建：KV、Worker、绑域名、等 /health
```

主机名自己定，落在账号里某个域名下即可，建议一个新子域名，不碰域名上已有的东西。建完写 `data/deploy.json`（host、export_url、export_key），主干循环每轮从这里读中转在哪、拿什么钥匙拉映射。跑第二遍不会多建，钥匙沿用。

[STEP:2|publish 推页面与 offer|by:agent]

```bash
python3 plugins/deploy/cloudflare/publish.py --site --site-name "Widget Reviews" --contact you@example.com   # /privacy /terms
python3 plugins/deploy/cloudflare/publish.py --page site/widget-x-review.html --slug widget-x-review         # 落地页
python3 plugins/deploy/cloudflare/publish.py --offers runs/<id>/offers-table.json                             # {offer_ref:{url,param}}
```

页面按 `core/lp/使用方法.md` 写好并过 `lp_check` 再推。offer 表里每个 offer_ref 对应一条联盟点击链接与 sub-id 参数名（CJ 是 `sid`）；加 offer 只是再推一次，合并不覆盖。

[STEP:3|status 真点一次|by:agent]

```bash
python3 plugins/deploy/cloudflare/status.py
python3 plugins/deploy/cloudflare/status.py --roundtrip --offer cj:100001:12345 --slug widget-x-review
```

三步：页面 200 且是 HTML、`/go` 回 302 且 location 带 `sid=<token>`、`/export` 里找得到这个 token 且 gclid 对得上。全通再 `core/ledger/subid.py pull` 看映射进账本。

## 实测记录

2026-09-25 用账号级全写 token 在 `reviews.aixray.dev` 实测：setup --apply 一次建好（KV、Worker 上传带绑定与 secret、自定义域名挂上后 Cloudflare 自动建 DNS 与证书，/health 约一分钟内通）；publish 推隐私条款页、落地页、offer 表；status --roundtrip 三步全通（页面 200、/go 302 带 sid、/export 查到 token）；teardown 拆净，账号里原有的 Worker、域名、KV 一个没动。钉下两条：`cfat_` 开头的账号 token 要在账号端点核（`/accounts/<id>/tokens/verify`），用户端点回 401；账号 token 看不了 registrar（买域名本来就是本人的事，不影响）。

::RULE{只建只改自己建的东西⇒账号里别的Worker_DNS_存储一律不碰}
::BOUNDARY{never:共享域名_桥页_按UA或IP改去向|scope:permanent}
